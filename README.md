# 🪙 Virtual Coin Toss Simulator (CLI Version)

A simple yet powerful Python-based command-line application that simulates a fair coin toss. It allows users to flip the coin multiple times and gives statistical results based on the outcome.

---

## 📌 Features

- 🎲 Simulates "Heads" or "Tails" using Python’s `random` module
- 🔁 Allows multiple flips in a single session
- 📊 Tracks count and percentage of each result
- 👤 User-friendly CLI interface with input validation
- 🔄 Option to repeat or exit after each session

---

## 🎯 Objectives

This project is built to help beginners strengthen their understanding of:
- ✅ Random number generation with `random.choice()`
- 🔁 Loops and conditional logic
- 🧮 Counters and basic statistics
- 🖥️ Command-line user interaction

---

## 🛠️ Tech Stack

| Purpose       | Tool/Library       |
|---------------|--------------------|

| Randomization | `random` module    |
| Interface     | Terminal (CLI)     |
